Checkers

About This Project

A fully functional checkers game featuring an AI opponent powered by the minimax algorithm with alpha-beta pruning for optimal decision-making.

Built entirely from scratch for the Problem Solving with AI class at Minerva University.

Unlike existing online implementations that many classmates relied on, this project was developed from the ground up to ensure technically correct game logic, proper rule enforcement (including mandatory captures and king promotion), and accurate AI behavior.

The game supports both Player vs AI and Player vs Player modes, with smooth animations and a responsive design that works on desktop and mobile.
