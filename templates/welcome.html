About this project

The Problem

Most online checkers games get the rules wrong. They ignore mandatory captures - the rule that if you can take an opponent's piece, you must. This fundamentally changes how the game is played and makes strategies less meaningful.

The Solution

This version implements proper checkers rules: mandatory captures, multi-jump sequences, and correct queen promotion. The board and pieces are rendered with pure CSS - no images, fully responsive.

The AI Opponent

The computer uses the minimax algorithm with alpha-beta pruning, searching 3 moves ahead. It evaluates positions by counting pieces and weighing queens more heavily. Simple but effective.

Course Project

Built for the Problem Solving with AI course at Minerva University. The goal was to implement a game-playing AI using classical search algorithms. Stack: Python Flask backend, vanilla JS frontend, Tailwind CSS.
