Checkers

by Liviu Orehovschi

Why build another checkers game?

Many online checkers implementations overlook a fundamental rule: mandatory captures. If you can capture, you must. I wanted to build a version that gets the rules right, including proper queen promotion and multi-jump sequences.

How it works

The board and checkers pieces are rendered entirely with CSS (gradients, shadows, and transforms). The computer opponent uses the minimax algorithm with alpha-beta pruning at depth 3, evaluating positions based on piece count and queen status.

Course project

Built as part of the Problem Solving with AI course at Minerva University.

Tech stack

Python (Flask) backend, vanilla JavaScript frontend, Tailwind CSS for styling. Deployed on Vercel.
